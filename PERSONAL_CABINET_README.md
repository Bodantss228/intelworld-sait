# IntelWorld - Личный кабинет

## Что добавлено:

### 🌐 Сайт (Next.js)

**Новые страницы:**
- `/login` - Страница входа с формой для ввода ника и кода
- `/profile` - Личный кабинет с балансом и историей транзакций

**API Routes:**
- `POST /api/auth/generate-code` - Генерация кода верификации
- `POST /api/auth/verify` - Проверка кода и создание JWT токена
- `POST /api/auth/logout` - Выход из аккаунта
- `GET /api/user/profile` - Получение профиля пользователя
- `GET /api/user/transactions` - История транзакций

**Безопасность:**
- JWT токены (срок жизни 7 дней)
- HttpOnly cookies (защита от XSS)
- Rate limiting (5 попыток за 10 минут)
- Одноразовые коды (живут 5 минут)

### 🎮 Minecraft Mod

**Новая команда:**
- `/account link` - Генерирует код для входа на сайт

**Что делает:**
1. Отправляет запрос на API сайта
2. Получает уникальный 6-значный код
3. Показывает красивое сообщение в чате с кодом
4. Код действителен 5 минут

## Как использовать:

### Для игроков:

1. **Зайдите на сервер** `play.intelworld.ru`
2. **Напишите команду** `/account link`
3. **Скопируйте код** из чата (например: ABC123)
4. **Откройте сайт** https://minecraftic.ru/login
5. **Введите ник и код**
6. **Готово!** Вы в личном кабинете

### Что можно делать в личном кабинете:

- ✅ Просматривать баланс в реальном времени
- ✅ Смотреть историю транзакций (последние 10)
- ✅ Видеть дату регистрации и последнего входа
- ✅ Видеть свой скин в 3D

## Установка и настройка:

### 1. Сайт (Vercel)

**Установить зависимости:**
```bash
cd "C:\Users\grinb\Downloads\сайт intel"
npm install
```

**Настроить переменные окружения:**
Файл `.env.local` уже создан, но можешь изменить:
```env
JWT_SECRET=твой-секретный-ключ-для-jwt
MINECRAFT_DATA_DIR=путь-к-данным-сервера (опционально)
```

**Запустить локально:**
```bash
npm run dev
```

**Задеплоить на Vercel:**
```bash
vercel --prod
```

**Важно!** Добавь переменные окружения в Vercel:
1. Открой проект на vercel.com
2. Settings → Environment Variables
3. Добавь `JWT_SECRET` с секретным ключом

### 2. Minecraft Mod

**Файлы:**
- `intelworld-bank-1.0.0.jar` - готовый мод в `build/libs/`

**Установка:**
1. Скопируй JAR в папку `mods` сервера
2. Перезапусти сервер
3. Готово!

**Команды:**
- `/account link` - получить код для входа
- `/bank balance` - проверить баланс
- `/bank deposit <игрок> <сумма>` - пополнить (банкир/оп)
- `/bank withdraw <игрок> <сумма>` - снять (банкир/оп)

## Структура данных:

Все данные хранятся в JSON файлах:

```
data/
├── accounts.json          # Аккаунты пользователей
├── verification-codes.json # Временные коды (автоочистка)
├── balances.json          # Балансы (из мода)
```

**accounts.json:**
```json
{
  "uuid-игрока": {
    "uuid": "...",
    "username": "Steve",
    "createdAt": 1713640000000,
    "lastLogin": 1713640000000
  }

```

**verification-codes.json:**
```json
[
  {
    "uuid": "...",
    "username": "Steve",
    "code": "ABC123",
    "expiresAt": 1713640300000
  }
]
```

## Безопасность:

### ✅ Что сделано:

1. **JWT токены** - безопасная авторизация
2. **HttpOnly cookies** - защита от XSS атак
3. **Rate limiting** - защита от брутфорса
4. **Одноразовые коды** - код удаляется после использования
5. **Короткий срок жизни** - коды живут 5 минут
6. **HTTPS** - весь трафик зашифрован (через Vercel)

### 🔒 Рекомендации:

1. **Измени JWT_SECRET** в продакшене на случайную строку
2. **Не коммить .env.local** в git (уже в .gitignore)
3. **Регулярно обновляй зависимости** (`npm update`)

## Troubleshooting:

### Проблема: "Не авторизован" при входе в /profile
**Решение:** Проверь что JWT_SECRET одинаковый в .env.local и на Vercel

### Проблема: Код не приходит в игре
**Решение:** 
1. Проверь что сервер может подключиться к API
2. Проверь URL в `AccountCommands.java` (должен быть твой домен)

### Проблема: "Неверный код" на сайте
**Решение:**
1. Код живет 5 минут - возможно истек
2. Проверь что ник написан правильно (регистр важен)
3. Попробуй сгенерировать новый код

### Проблема: Транзакции не отображаются
**Решение:** Проверь что файл `transactions.json` существует и доступен для чтения
