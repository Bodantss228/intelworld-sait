# IntelWorld - Официальный сайт

Профессиональный сайт для Minecraft сервера IntelWorld (Юбилейный 5-й сезон "What If...").

## О проекте

IntelWorld - ванилла+ сервер на Fabric 1.21.x с уникальной экосистемой, включающей банковскую систему, маркетплейсы и ИИ-персонажа Клео.

### Тема сезона 5: "What If..."
Исследование альтернативных реальностей вселенной IntelWorld. Нексус Времени, временные аномалии, мультивселенная.

## Особенности

### Дизайн
- Темный премиальный стиль (черный, золото, пурпурные акценты)
- Кинематографичная атмосфера
- Плавные анимации (Framer Motion)
- Полностью адаптивный дизайн

### Страницы
- **Главная** - Hero секция с информацией о сезоне
- **Экосистема** - Банк, Авито, WB, ИИ Клео
- **Архив** - Интерактивная история всех 5 сезонов
- **Карта** - Интеграция Dynmap
- **Статистика** - Топ игроков и достижения
- **Скачать** - Модпак и инструкции

### Экосистема IntelWorld
1. **Банковская система** - Алмазы как валюта, синхронизация с Telegram
2. **Авито** - Торговая площадка для ресурсов и услуг
3. **WB (Wildberries)** - Обмен кастомными 3D-моделями (CPM)
4. **ИИ Клео** - Персональный ассистент на базе API Алисы

### Временные аномалии (Ивенты)
- Тетрадь Смерти
- Остановка времени
- Вселение
- Зомби-апокалипсис
- Шкатулки Одена

## Технологии

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## API Endpoints

- `GET /api/players` - Список игроков онлайн
- `GET /api/stats` - Статистика сервера
- `GET /api/bank/[playerId]` - Баланс игрока

## Настройка

### Dynmap
Замените URL в `app/map/page.tsx`:
```typescript
src="http://your-dynmap-url.com"
```

### Mock данные
Отредактируйте файлы в `/data`:
- `players.json` - Игроки онлайн
- `bank.json` - Банковские балансы
- `stats.json` - Статистика сервера
