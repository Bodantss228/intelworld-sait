## 🚀 Установка:

### 1. Установи мод на сервер:
```bash
# Скопируй JAR в папку mods
cp "C:\Users\grinb\mod bank\build\libs\intelworld-bank-1.0.0.jar" /path/to/server/mods/

# Перезапусти сервер
```

### 2. Настрой переменные окружения на Vercel:

Добавь в Vercel (Settings → Environment Variables):
```
MINECRAFT_SERVER_URL=http://ВАШ_IP_СЕРВЕРА:8080
```

**Важно!** Замени `ВАШ_IP_СЕРВЕРА` на реальный IP сервера Minecraft.

Например:
- `http://play.intelworld.ru:8080`
- `http://123.45.67.89:8080`

### 3. Открой порт 8080 на сервере:

Если используешь firewall:
```bash
# Ubuntu/Debian
sudo ufw allow 8080/tcp

# CentOS/RHEL
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

Если используешь хостинг - открой порт 8080 в панели управления.

## 🔧 Как это работает:

### Схема авторизации:

```
1. Игрок → /account link
   ↓
2. Мод генерирует код (хранится в памяти мода)
   ↓
3. Игрок вводит ник + код на сайте
   ↓
4. Сайт → HTTP запрос к моду (порт 8080)
   ↓
5. Мод проверяет код
   ↓
6. Сайт создает JWT токен
   ↓
7. Игрок авторизован!
```

### API Endpoints мода:

**POST** `http://SERVER:8080/api/auth/verify`
```json
Request:
{
  "username": "Steve",
  "code": "ABC123"
}

Response (success):
{
  "success": true,
  "uuid": "...",
  "username": "Steve"
}

Response (error):
{
  "error": "Неверный код или истек срок действия"
}
```

**GET** `http://SERVER:8080/api/bank/balance?uuid=...`
```json
Response:
{
  "balance": 15420
}
```

## ⚠️ Важные моменты:

### Безопасность:

1. **Порт 8080 открыт** - это нормально, API публичный
2. **Коды одноразовые** - после использования удаляются
3. **Коды живут 5 минут** - автоматически удаляются
4. **Rate limiting** - на сайте (5 попыток за 10 минут)

### Если сервер за NAT:

Если сервер за роутером, нужно:
1. Пробросить порт 8080 на роутере
2. Использовать внешний IP в `MINECRAFT_SERVER_URL`

### Если используешь прокси (BungeeCord/Velocity):

API работает на backend сервере, не на прокси.
Используй IP backend сервера в `MINECRAFT_SERVER_URL`.

## 🐛 Troubleshooting:

### "Не удалось подключиться к серверу"
**Причина:** Сайт не может достучаться до API мода  
**Решение:**
1. Проверь что порт 8080 открыт
2. Проверь `MINECRAFT_SERVER_URL` на Vercel
3. Проверь что мод запущен (в логах должно быть "Bank API Server started on port 8080")

### "Неверный код"
**Причина:** Код истек или неправильно введен  
**Решение:**
1. Коды живут 5 минут - генерируй новый
2. Проверь регистр (код чувствителен к регистру)
3. Проверь что ник написан правильно

### Мод не запускается
**Причина:** Порт 8080 уже занят  
**Решение:**
1. Проверь что порт свободен: `netstat -an | grep 8080`
2. Останови процесс на порту 8080
3. Или измени порт в коде мода (BankApiServer.java, строка 18)
